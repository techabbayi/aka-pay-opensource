# Security Policy — AKA PAY

## Supported Versions

Only the latest release of AKA PAY on `main` branch is supported with security patches.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The AKA PAY team and maintainers take security and payment invariants seriously.

If you believe you have found a security vulnerability in AKA PAY, please **do not** open a public issue on GitHub. Instead, report it privately to the maintainer:

* **Contact Email:** [srssltd@gmail.com](mailto:srssltd@gmail.com)
* **Lead Maintainer:** [techabbayi](https://github.com/techabbayi) (Lokeswara Muthumula)
* **LinkedIn:** [https://in.linkedin.com/in/lokeswaramuthumula](https://in.linkedin.com/in/lokeswaramuthumula)

Please include:
1. Detailed description of the vulnerability and attack vector.
2. Steps to reproduce or proof-of-concept payload.
3. Impact assessment on payment state machine, raw webhook signatures, or observer streams.

We will acknowledge receipt within 48 hours and work with you on remediation before any public disclosure.
